- **Dedicated Services Breakdown (`/services`)**: In-depth detailing of custom web development, digital marketing & SEO, and AI automation; includes a filterable 20+ production tool stack matrix and an interactive scope & timeline estimator.
- **Dedicated Hire & Resume Portal (`/hire`)**:
  - **Official Interactive Curriculum Vitae (CV)** with Print / PDF export and shareable link.
  - **Live GitHub Outlet** showcasing [@samriidhpandey](https://github.com/samriidhpandey), public repositories, and commit stats.
  - **Live LinkedIn Outlet** with verified credential badges and direct connection CTA.
  - **Real-Time Status Telemetry**: Live local clock, response time guarantee (< 2 hours), and 1-click WhatsApp/Email triggers.
- **Interactive AI Lab Terminal**: Full-width interactive UNIX-style shell emulator (`samridh@core:~$`) supporting commands like `help`, `about`, `skills`, `projects`, `eval`, and `clear`.
- **3D Tilt Projects Showcase**: Dossier modals with architecture breakdowns and live preview links.
- **Interactive Web Audio System**: Synthesizer sound effects built with the Web Audio API.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/samriidhpandey/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to view the live site.
